# Java for CMSC 130

*Java for CMSC 130* builds on the programming foundations introduced in *Java for CMSC 120*. It emphasizes the cornerstones of object-oriented programming: abstraction, encapsulation, inheritance, and polymorphism. GUI construction and exception handling are covered as practical applications.

The original text is no longer available, but the source code remains in `code/src/`. The table of contents reflects the source code's organization.
