# Java for CMSC 130

*Java for CMSC 130* builds on the programming foundations introduced in *Java for CMSC 120*, which introduced readers with no prior programming experience to object-oriented programming in Java. While the earlier material emphasized creating and using objects from existing library classes, this text focuses on the cornerstones of object-oriented programming: defining custom classes, designing interfaces, and understanding inheritance and polymorphism. The goal is to develop a deeper understanding of how objects are constructed, how they interact, and how object-oriented principles support clear, modular, and well-organized programs.

The material covers the fundamental concepts and techniques needed to design and implement object-oriented programs in Java. Through practical examples and case studies, readers explore abstraction, encapsulation, constructors, methods, interfaces, event handling, inheritance, polymorphism, and exception handling.

All source code can be found under code/src/
